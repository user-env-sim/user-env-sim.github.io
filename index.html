About The Workshop

Modeling interaction before it reaches the real world.

The workshop brings together researchers and practitioners building simulations of users, tasks, environments, and interactive systems. Topics include synthetic user behavior, environment generation, agent evaluation, benchmark design, human-centered simulation, and trustworthy deployment of simulated feedback loops.

Themes

Workshop Topics

User Simulation

Behavioral modeling, preference drift, multi-turn interaction, and persona-conditioned evaluation.

Environment Simulation

World models, task environments, controllable perturbations, and synthetic testbeds.

Evaluation Systems

Metrics, failure analysis, reproducibility, simulation fidelity, and deployment readiness.
